# 映画『マトリックス』の源流：ウォシャウスキー姉妹の初期ビジョンと哲学

[BANNER]: /Users/yukinari/Desktop/antigravity/projects/prosper/images/matrix_vision_letterbox.png

1999年に公開され、映像革命と共に世界中に衝撃を与えた映画『マトリックス』。
その圧倒的なビジュアルの背後には、監督であるウォシャウスキー姉妹（当時兄弟）の並々ならぬ哲学と、多様なカルチャーからの影響が隠されていました。

今回は、彼女たちの初期ビジョンと、作品の根底に流れる思想の源流を探ります。

## 次世代のコーエン兄弟と呼ばれた異才

ウォシャウスキー姉妹の長編デビュー作は、1996年のネオノワール映画『バウンド』でした。
当初、彼女たちは「次世代のコーエン兄弟」として映画界から注目を集めていました。

ラナ・ウォシャウスキーは1999年当時、「私たちがこれまでの人生で抱いたあらゆるアイデアがこの映画（『マトリックス』）に含まれている」と語っています。その言葉通り、本作は単なるSFアクションの枠に収まらない、膨大な情報のパッチワークとなっています。

## 融合するカルチャー：サイバーパンクから日本アニメまで

彼女たちが目指したのは、全く異なるジャンルの融合でした。

*   **サイバーパンク・フィクション**（ウィリアム・ギブスンなど）
*   **コミック**
*   **コンピューターゲーム**
*   **日本のアニメーション**

これらをベースに、ルイス・キャロルの『不思議の国のアリス』や聖書、ギリシャ神話、さらには東洋思想までをも取り込んでいます。

特に日本のアニメからの影響は色濃く、『GHOST IN THE SHELL / 攻殻機動隊』（押井守監督）の実写化を志向していたことは有名なエピソードです。オープニングの「マトリックス・デジタル・レイン」が、実は日本人の妻を持つデザイナーによる「寿司のレシピ」からインスパイアされているという逸話も、彼女たちの日本カルチャーへの親愛を感じさせます。

## トランスジェンダーの寓話としての側面

近年、リリー・ウォシャウスキーによって明かされた事実があります。
それは、『マトリックス』三部作が「トランスジェンダーとして生きることの寓話」であったという視点です。

当初の構想では、現実世界と仮想空間（マトリックス）を行き来する際、キャラクターの性別が変わるという設定も考えられていました。残念ながら、当時の社会情勢や実業界の理解が追いつかず、この設定はストレートには表現されませんでした。

しかし、「支配のシステム」からの解放、「自分が何者かは自分が決める」という強いメッセージは、間違いなく彼女たちの内なる叫びから生まれたものでしょう。

> 「私たちは常に想像の世界に生きていて、『新しい世界』を作り上げることに夢中だった」

リリーが語るように、既存の枠組みを超えようとする想像力こそが、『マトリックス』という傑作を生みだしたのです。
