# Prosper Investigator (v2) 仕様書

## 1. 動作フロー
`investigator.py "テーマ"` を実行すると、以下のステップ順に処理が行われます。

1.  **起動 & 設定読み込み**:
    *   `.env` からAPIキーを読み込み。
    *   `RESEARCH_RULES.md`（調査の憲法）を読み込み、システムプロンプトに組み込む。

2.  **Gemini API へのリクエスト**:
    *   以下の指示をGeminiに送ります。
        > 「[テーマ]について、[ルール]を守りながら、Google検索機能を使って調査し、レポートを書け」
    *   この時、**Google Search Grounding（検索グラウンディング）** 機能がONになります。

3.  **Geminiによる自律検索 (裏側の処理)**:
    *   Geminiが「この回答には最新情報が必要だ」と判断し、自動的にGoogle検索を実行します。
    *   検索クエリ例: `AIエージェント トレンド 2026`, `AI Agents market size 2026`, `physical AI trends Japan` など
    *   検索結果（複数のWebページの内容）をAIが読み込みます。

4.  **分析 & レポート生成**:
    *   読み込んだ検索結果と、自身の知識を統合します。
    *   `RESEARCH_RULES.md` に従い、情報の取捨選択、出典の紐付け (`[Title](URL)`) を行います。
    *   Markdown形式のレポートを生成して出力します。

## 2. API使用量とコスト予想 (Gemini 2.5 Flash)

Google AI StudioのAPIキーを使用しているため、**現時点では無料枠の範囲内で十分に収まります。**

### ✅ コスト計算式
*   **モデル**: `gemini-2.5-flash` (または `1.5-flash`)
*   **単価**: 無料枠内なら $0
*   **無料枠**: 1日あたり 1,500 リクエストまで (従来のFlashモデル基準)

### 📊 1回の実行あたりの消費量（概算）
| 項目 | トークン数 / 回数 | 備考 |
| :--- | :--- | :--- |
| **入力トークン** | 約 3,000 ~ 5,000 tokens | ルール定義 + 検索結果により変動 |
| **出力トークン** | 約 2,000 ~ 4,000 tokens | レポートの長さに依存 |
| **検索実行回数** | 1 Grounding Request | 1回のAPIコール内で処理される |

### 💰 結論
*   **個人利用レベル（1日数十回程度の実行）であれば、完全に無料です。**
*   有料枠（Pay-as-you-go）に移行した場合でも、Flashモデルは非常に安価（入力100万トークンあたり$0.10程度）なため、1回の調査あたり **0.1円未満** です。
*   ただし、将来的にGoogle Search Groundingが有料化される可能性はありますが、現在はAI Studio経由であれば課金されません。

## 3. 注意点
*   **Google検索のバイアス**: 検索上位の情報に影響されやすいため、`RESEARCH_RULES.md` で「多様な視点」を強制することが重要です（実装済み）。
*   **ハルシネーション抑制**: Grounding機能により、検索結果にない情報は「書かない」あるいは検索結果に基づいて回答するため、嘘をつく確率は大幅に下がります。
