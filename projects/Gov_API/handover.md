# プロジェクト引き継ぎ資料 (Handover Document)

## 1. プロジェクト概要
- **名称**: `Gov_API` (売るとき相場チェッカー)
- **目的**: 国土交通省の不動産取引価格APIを活用し、ユーザーが匿名・無料で自分の物件の市場価値をセルフチェックできるダッシュボード。
- **ターゲット**: 不動産売却を検討しており、営業電話を避けつつ正確な成約価格を知りたいユーザー。

## 2. 技術スタック
- **Framework**: Next.js 15.1.6 (App Router)
- **Styling**: Tailwind CSS 4.0
- **Visualization**: 
    - Recharts (価格推移トレンド)
    - React Leaflet (地図表示 - 構造のみ。現在は一覧表示がメイン)
- **Icons**: Lucide React
- **Deployment**: Cloudflare Pages (OpenNext, Edge Runtime)
- **Domain**: `gov.moguruu.com` 稼働中

## 3. システムアーキテクチャ
- **Frontend**: `src/app/page.tsx` がメインのエントリポイント。コンポーネント指向で設計。
- **API (Proxy)**: `src/app/api/reins/route.ts`
    - 国土交通省API (MLIT) へのプロキシ。
    - APIキー (`REINS_API_KEY`) は環境変数で管理。
    - レート制限 (20req/min/IP) を実装済み。
- **Data Flow**: `api-client.ts` がAPIを叩き、`page.tsx` で取得・フィルタリング・統計計算を行う。

## 4. 重要な実装履歴と設計判断
- **レイアウトのフラット化**: 初期はタブ形式だったが、アクセシビリティ向上のため「サマリー → チャート → 一覧」の縦長フラット配置に変更。
- **単価計算の堅牢化**: 大阪などの地方都市で「平米単価」がAPIから返らない場合、`TradePrice / Area` で動的に算出するフォールバックを実装。
- **デザインの変遷 (重要)**:
    - **フェーズ1**: 白一色の極めてシンプルな状態。
    - **フェーズ2**: 「データ・インサイト」案の実装。SVGパターンや多重グラデーション、透過カードを追加したが、「薄汚れて見える」とのフィードバックを受け破棄。
    - **現在 (フェーズ3)**: 「高精度クリーン」デザイン。ノイズを排除し、`stone-50` の背景とソリッドな白カード、精緻な影を用いたミニマルで清潔感のあるUI。

## 6. AI向けのアドバイス
- **デザイン傾向**: ユーザーは「装飾」よりも「清潔感・可読性・信頼感」を重視します。過度なグラデーションやパターンは避けてください。
- **データの扱い**: 国交省APIはデータ形式が不統一な場合があります（単位、欠損値など）。計算ロジックを変更する際は、`api-client.ts` と `page.tsx` 内の `useMemo` でのフィルタリングに注目してください。
