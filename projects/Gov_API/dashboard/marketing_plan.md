# タウンライフアフィリエイト導入ロードマップ

現在の「売るとき相場チェッカー」のソースコードを確認し、アフィリエイトリンクのプレースホルダーと該当箇所のUIコピーを把握しました。
「不要なトラブルを避けつつ、最大限の送客（コンバージョン）を狙う」という目標を達成するため、以下のステップで実装を進めます。

## 1. プログラム選定とリンク取得（対応ステータス：承認待ち）
当アプリのコンテキスト（自分の家の相場を知りたい）において、コンバージョンと単価を最大化するため、**「おうちクラベル 不動産売却一括査定サービス」** のプログラムを選定し、現在提携申請中です（承認後リンク取得可能）。

**選定理由（1プログラムに絞った理由）:**
1. **高単価（14,400円/件）**: 一般的な査定案件の中でもトップクラスの報酬額。
2. **高い信頼性**: ソニーグループ（SREホールディングス）のサービスであり、ユーザーが安心して申し込める。
3. **迷いを防ぐ（決定回避の法則の回避）**: 「買取」など複数の選択肢を同時に提示するとユーザーのコンバージョン率が大きく下がるため、最もニーズに直結する一括査定1本に絞り込んで誘導の確度を最大化します。

## 2. UIコピーのリスク管理と最適化（最重要）

現在、コード内には以下のような強力な訴求がハードコードされています。
- `完全に匿名・営業電話なしの「机上査定」`
- `メール連絡を優先的に選択可能`

**🚨 トラブル防止（景品表示法・規約違反対策）**
一括査定サイト全般の仕様として、「完全に匿名」での査定は基本的に不可能（物件情報や連絡先の入力が必須）です。また、不動産会社によっては電話がかかってくる可能性があります。
「絶対電話がかかってこない」「完全匿名」と言い切ってしまうと、**「嘘をつかれた」とユーザークレームに繋がり、最悪の場合アフィリエイト提携解除（成果没収）**のリスクがあります。

**✅ 改善案（誠実かつクリックしたくなるコピーへの変更）**
嘘をつかず、かつ心理的ハードルを下げるコピーに変更します。
- 変更前: 「営業電話なし・完全匿名の「机上査定」で確認できます」
- 変更後: **「まずは価格だけ知りたい場合は、備考欄に「机上査定・メール連絡希望」と記載するのがおすすめです」**
- コピーのトーン: 「相場データだけではわからない、『今の実際の最高値』をプロに無料査定してもらう」という文脈を強化し、自然なステップアップとして誘導します。
