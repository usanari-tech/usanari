# Product Concept & Value Proposition: "Spicy" (working title)

「何を作るか」を明確にし、市場で勝てる（収益化できる）アプリを定義します。

## 1. Core Value (なぜこのアプリなのか？)
既存の食事管理アプリ（あすけん等）は「優等生」で「優しい」。しかし、多くの人は優しくされても続かない、あるいは嘘をついてしまう。
**"Spicy"** は、**「真実を突きつけられる快感」** と **「罵倒されることで生じる反骨精神」** をエネルギーに変える、世界初の **"Masochistic Health App"** です。

### 提供する価値
1.  **容赦ない真実**: カロリーオーバーや栄養の偏りを、一切のオブラート無しで指摘。
2.  **エンターテイメント**: 辛口コメント自体がコンテンツとして面白い（シェアしたくなる）。
3.  **継続性**: 「次は褒めさせてやる」「悔しい」という感情的フックによる継続率向上。

## 2. Target Audience (誰のためのアプリか？)
*   **「褒められて伸びない」タイプ**: 優しいアドバイスでは甘えてしまう人。
*   **ダイエット挫折経験者**: 既存アプリの入力が面倒、または「良い子」を演じるのに疲れた人。
*   **Z世代〜ミレニアル世代**: ネタ消費として友人とスクショを共有したい層。
*   **ストイックな筋トレ層**: 余計な慰めよりも、ファクトと数字による厳しいフィードバックを好む層。

## 3. MVP Features (最小限の機能)
収益化のために「これだけは必須」な機能。

*   **Photo to Analysis (AI)**: 食事写真を撮るだけで、即座にカロリー計算＆罵倒コメント生成。(Core Tech)
*   **History & Trends**: 過去の「罪」をカレンダーで可視化。赤（最悪）が続くとキャラクターの機嫌が悪化。
*   **Character Voice (Optional -> Future)**: 文字だけでなく、音声で罵倒される機能（課金要素として強力）。
*   **Level System**: 罵倒され続けると「耐性」がつき、より辛辣なモードが解放される、あるいは逆に「デレ」が見られる？

## 4. Monetization Points (どこで稼ぐか)
*   **Free**: 1日3食までの解析、広告あり。
*   **Pro (Subscription ¥500/mo)**: 
    *   無制限解析。
    *   過去ログ無制限閲覧。
    *   広告除去。
    *   **「激辛モード」解放**（性格変更）。

## 5. Risk Assessment (懸念点)
*   **App Store Review**: 「過度な攻撃性」や「ハラスメント」と判定されないか？ -> **"ユーモア"と"キャラクター性"で包む必要がある。**
*   **User Retention**: 最初は面白くても、毎日罵倒されると本当に嫌になって辞める可能性。 -> **アメとムチのバランス（10回に1回のデレ）が重要。**
