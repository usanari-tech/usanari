# 就労支援A型事業所 干し芋EC立ち上げアドバイス＆戦略シート

## 1. 最初に伝えるべき「最強の強み」
「知識がない」と不安に思われていますが、実は就労支援A型事業所はEC運営において**最強の武器**を持っています。自信を持って以下を伝えてあげてください。

*   **「丁寧な手作業」という武器**: 一般企業がコスト削減で排除する「丁寧な検品」「手書きのメッセージ」「複雑で綺麗な梱包」を、利用者さんの業務として付加価値に変えられます。これはECのレビュー評価（リピート率）に直結します。
*   **「ストーリー」という武器**: 「誰が、どんな想いで作ったか」が見える商品は、ただの食品以上の価値（応援消費）を生みます。
*   **「チーム運営」**: 孤独になりがちなEC運営を、利用者さんと一緒にチームで回せるのは強みです。

## 2. まず確認するヒアリングリスト（電話用）
相手の状況を整理し、的確なアドバイスをするために聞いてみてください。

- [ ] **目標**: 「月にどれしくらい売りたいか？」（例: 月5万なら今の延長、月50万なら広告や新商品が必要）
- [ ] **利用者さんのスキル**: 
    - PCが得意な人はいるか？（商品登録、SNS更新）
    - 絵や文字が得意な人はいるか？（サンクスカード、ロゴ作成）
    - 几帳面な作業が得意な人はいるか？（梱包、計量）
- [ ] **今の「食べチョク」の状況**: 
    - レビューは付いているか？（付いていないなら、まずはここに注力）
    - 商品写真は誰が撮っているか？（ここが一番重要）
- [ ] **予算**: 広告費はかけられるか、極力0円でいくか？（基本は0円スタート推奨）

## 3. 具体的なアクションプラン（明日からできること）

### 【短期】食べチョク・既存販路での売上アップ
1.  **「同梱物」でファンを作る（最重要）**
    *   商品に**「手書きのサンクスカード」**を入れる。
    *   利用者さんが書いたイラストや、「私たちが袋詰めしました」という紹介チラシを入れる。
    *   これにより「ただの干し芋」が「あそこで作っている温かい干し芋」に変わります。
2.  **写真と説明文の見直し**
    *   写真はスマホでOK。**「自然光（窓際）」**で撮るだけで美味しそうに見えます。
    *   断面のアップ、手に持ったサイズ感、パッケージの状態など、写真を増やす。
3.  **食べチョクの「投稿機能」活用**
    *   農作業や加工の様子をこまめに投稿する。
    *   「利用者さんが丁寧に選別しています」というプロセス自体がコンテンツになります。

### 【中長期】自社EC・販路拡大
1.  **自社ECプラットフォームの選定**
    *   おすすめは **[BASE](https://thebase.in/)** または **[STORES](https://stores.jp/)**。
    *   **理由**: 初期費用・月額無料プランがあり、操作がスマホでもできるほど簡単。利用者さんへのPC作業切り出し（商品登録や発送処理）が一番やりやすいです。Shopifyは高機能ですが、初心者の初手としてはコストと学習コストが高い可能性があります。
2.  **商品開発（松竹梅を作る）**
    *   **梅（訳あり品）**: 形が不揃いなものを安く。自宅用。
    *   **竹（通常品）**: スタンダードなパック。
    *   **松（贈答用）**: ここが利益の源泉。箱入り、高級紙の帯など、「ギフト」として使える高単価商品を作る。企業のお歳暮や手土産需要を狙う。
3.  **SNS活用（Instagram/Note）**
    *   「干し芋のアレンジレシピ」（トースターで焼く、アイスを乗せるなど）を発信。
    *   「就労支援A型の日常」を発信し、応援してくれるファン（フォロワー）を増やす。

## 4. 利用者さんへの業務切り出し（タスク分解）
EC運営は細かい作業の集合体です。これを利用者さんの「仕事」として切り出すことで、事業所としての売上＝利用者さんの工賃アップに繋がります。

| 業務 | 具体的な作業内容 | 難易度 |
| :--- | :--- | :--- |
| **ささげ業務** | 商品の採寸、重さ計量、撮影補助、画像リネーム | ★☆☆ |
| **梱包・発送** | サンクスカード封入、箱の組み立て、ラベル貼り、丁寧な梱包 | ★☆☆ |
| **制作** | 手書きサンクスカード作成、ダンボールへのスタンプ押し、チラシ折り | ★★☆ |
| **CS・管理** | 在庫カウント、PCでの注文確認、発送完了メール送信（テンプレあり） | ★★★ |
| **クリエイティブ** | SNS用の写真撮影、簡単な画像加工（Canvaなど）、ブログ下書き | ★★★ |

## 5. 勉強のためのリソース
「マーケティングの素人」でも大丈夫です。以下の視点でインプットをおすすめしてください。

*   **キーワード検索**: 「農福連携 EC 事例」「BASE　食品　販売事例」
*   **本**: 『おうち起業の教科書』や『BASEでネットショップを開設・運営するための本』など、初心者向けの図解が多い本が1冊あれば十分です。
*   **一番の勉強**: **「売れている同業者の干し芋を買ってみること」**。
    *   どんな箱で届くか？
    *   どんなチラシが入っているか？
    *   食べた後、どんなメールが来るか？
    *   これらを真似する（TTP＝徹底的にパクる）のが最短の近道です。
