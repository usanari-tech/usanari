# 干し芋EC 競合TTP（徹底的にパクる）レポート

最大手および特徴的な成功店舗を調査した結果、**「芋國屋」「塚田商店」**の2強と、ブランド戦略の**「ほしいもの百貨」**をベンチマークすべきです。

## 1. 【最大手】芋國屋（いもくにや）
**楽天ショップ・オブ・ザ・イヤー受賞の圧倒的王者。**
「安くて美味しい」をこれでもかと訴求するスタイル。

### 🚀 TTP（パクる）ポイント
*   **「訳あり」を主力フックにする**:
    *   商品名にあえて「訳あり」と入れ、**「形は悪いけど味は一緒、だから安い」**という納得感を演出。
    *   **アクション**: 製造過程で出る不揃い品を「ご家庭用・訳ありパック」として、簡易包装（透明なナイロン袋＋シールのみ）で安く出す。これがレビューを稼ぐエンジンになります。
*   **レビュー数の「権威付け」**:
    *   LPの冒頭で「レビュー○○件突破！」「ランキング1位」をデカデカと見せる。
    *   **アクション**: 食べチョクなどでの実績ができたら、キャプチャを撮って商品ページに貼り付ける。「みんな買ってる」安心感を作ります。
*   **「冷凍」の提案**:
    *   「届いたら小分けして冷凍すれば長持ち」という**保存方法の教育**を徹底している。これにより、1kgなどの大容量買いに対するハードルを下げています。

## 2. 【品質の王道】塚田商店（つかだしょうてん）
**「マツコの知らない世界」で絶賛された品質特化型。**
余計なことをせず、素材の良さをシンプルに伝えるスタイル。

### 🚀 TTP（パクる）ポイント
*   **シズル感のある「断面アップ」写真**:
    *   干し芋を割った時の**「ねっとり感」「黄金色」**が伝わる超接写画像を多用。
    *   **アクション**: 自然光（窓際）で、干し芋を指で裂いている瞬間の写真を撮る。これが一番美味しそうに見えます。
*   **「余計なものは一切なし」の引き算訴求**:
    *   「原材料：さつまいも」のみであることを強調。
    *   **アクション**: 就労支援A型の手作りであることを活かし、「機械乾燥ではなく、天日干し（または手作業での丁寧な加工）」という**手間暇**を品質の証拠として書く。

## 3. 【ブランドのお手本】ほしいもの百貨
**ギフト需要・高単価狙いの参考事例。**
「ただの芋」を「贈り物」に変えるデザイン力。

### 🚀 TTP（パクる）ポイント
*   **パッケージの「クラフト感」**:
    *   高級な箱を使わなくても、**クラフト紙（茶封筒のような素材）の袋**に、黒1色のシンプルなロゴシールを貼るだけで「オーガニックで高級」に見えます。
    *   **アクション**: デザインに予算をかけられない場合、無地のクラフト袋＋ハンコ（利用者さんが押す）で十分ブランド感が出ます。
*   **カフェ的な世界観**:
    *   お皿に載せて、コーヒーと一緒に撮るなど「おやつタイム」を提案。

## 4. 就労支援A型としての「勝ち筋」まとめ

競合調査から見えた、今すぐやるべき「TTP」構成案です。

1.  **商品ラインナップ**:
    *   **集客用**: 「訳あり 1kg（簡易包装）」 → 芋國屋をTTP
    *   **利益用**: 「贈答用 ギフトBOX」 → ほしいもの百貨をTTP
2.  **商品写真**:
    *   **1枚目**: 接写で「黄金色のねっとり感」を見せる（塚田商店TTP）
    *   **2枚目**: 「就労支援A型のみんなで作りました」という作業風景（独自性）
3.  **同梱物**:
    *   これだけは大手ECは真似できません。**「手書きのメッセージカード」**を必ず入れる。これでリピート率が劇的に変わります。

まずは**「芋國屋」の「訳あり品の見せ方」**と**「塚田商店」の「写真の撮り方」**、この2点を真似ることから始めてください。
