# visualize-md

現在のディレクトリ（または指定されたディレクトリ）にあるMarkdownファイルを、ブラウザで閲覧するためのビューワーを起動します。

## 概要
Next.js製のMarkdown Viewerアプリを起動し、環境変数 `MD_SOURCE_DIR` で指定されたフォルダ（デフォルトはカレントディレクトリ）内のMarkdownファイルを表示します。

## 手順

1.  **対象ディレクトリの特定**
    *   ユーザーがディレクトリを指定している場合はそのパスを使用します。
    *   指定がない場合は、現在の**カレントワーキングディレクトリ(CWD)**を使用します。
    *   パスは必ず**絶対パス**に変換してください。

2.  **Viewerの起動**
    *   Viewerのソースコードは、このスキルのディレクトリ内の `viewer` フォルダにあります。
    *   以下のコマンドをバックグラウンドで実行します。
    
    ```bash
    # ポート競合を避けるため、空いているポートを探すか、Next.jsの自動割り当てに任せます。
    # MD_SOURCE_DIR は対象のMarkdownファイルがあるディレクトリの絶対パスです。
    export MD_SOURCE_DIR="/absolute/path/to/target/dir"
    cd {{skill_dir}}/viewer
    npm run dev
    ```

3.  **URLの通知と起動**
    *   コマンド出力から起動したポート（例: `http://localhost:3000` や `3001`）を確認します。
    *   **重要**: ユーザーの手間を省くため、以下のコマンドを実行してユーザーの既定ブラウザで自動的に開いてください。
        ```bash
        open http://localhost:300x
        ```
    *   最後にユーザーに「Markdown Viewerを起動し、ブラウザで開きました」と報告します。

## ヒント
*   依存関係 (`node_modules`) は `viewer` ディレクトリ内にインストール済みであることを想定しています。もしない場合は `npm install` を実行してください。
*   ユーザーが終了を求めた場合は、起動したプロセスを停止してください。
